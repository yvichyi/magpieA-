# Magpie Android 2.0.0-preview1 验证记录

2026 年 11 月 18 日在 Android 15（API 35）SDK 模拟器上验收已签名的 x86_64 构建。版本号为 14，包名为 `ai.magpie.android`。内置 Magpie 核心使用 `0.1.4342`（`593517bf00bc8b0ab00c8ddef3f4d31b310a71b8`），Bun 使用 `1.4.2`。

| 范围 | 实测结果 |
| --- | --- |
| 覆盖安装 | 从 1.12 覆盖安装后仍可读取原有服务商配置。 |
| 接入 | 通过原生表单保存服务商，从网关读取模型，查看模型详情，创建分组并核对其成员。分别向 OpenAI、Anthropic、Gemini 兼容入口发起测试，核对实际响应与剪贴板配置。 |
| 插件 | 使用内置 Bun 在本地 npm 测试仓库安装插件，停用、重新启用、检查并更新到 1.0.2。 |
| 用量 | 用量概览、Token 构成、日历、请求记录和明细可打开。经系统文件选择器保存 CSV 后读回了 9 行、每行 47 个字段。返回设置前的请求列表。 |
| 备份 | 内置核心创建加密备份，拒绝错误密码，再用正确密码恢复测试工作空间。 |
| 折射 | 最终 x86_64 包在 API 35 上使用原生 AGSL。更改底栏下方内容后，底栏采样像素随之改变。 |
| 应用测试 | 20 个 JVM 测试入口及 API 28 Java 库链接检查通过。24 项 Chromium 测试通过，覆盖高级页导航、窄屏、保存拦截及插件安装异常。 |
| APK | 两个包通过签名、包名、版本号、ABI 和 16 KB ZIP 对齐检查。签名与 1.12 一致，两个架构的 DEX 一致。通过无登录的 GitHub 地址完整下载两个包，并核对长度与 SHA-256。 |

覆盖安装、接入、插件和用量的整套流程在排版修订前的签名候选包上通过。最终包完成了单行字标、标签和筛选栏间距及大字模式底栏遮罩调整，签名和折射复验通过。模拟器曾在冷启动时读取目录超时，页面提供重试入口。模拟器随后因资源限制中断，最终包的整套重跑尚未完成。

服务商兼容入口与 npm 安装使用隔离测试源。ARM64 已完成包与签名校验。实体手机、旧系统真机性能及各服务商的外部 OAuth 登录待实机验证。
