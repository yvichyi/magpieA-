# Magpie Android 2.0 预览 6

## 订阅签到

打开「用量 → 签到」，或在「设置 → 用量」中打开「签到」。页面显示当前工作区里支持签到的订阅账号。可单独签到，为当天还没签到的账号批量操作，或单独设置服务商和账号的每日自动签到。服务商要求验证码或自家客户端时，页面显示对应指引。

签到调用内置 Magpie 核心的原版接口，支持由该工作区返回的 WorkBuddy 国内版、Trae CN、MiniMax Code、Qoder 及实现了签到的插件账号。工作区需要先登录相应的订阅账号。[原版接口](https://github.com/yetone/magpie/blob/v0.1.4342/internal/gui/usage.go) · [原版设置接口](https://github.com/yetone/magpie/blob/v0.1.4342/internal/gui/api.go)

## 背景和交互

建筑照片已移除。液态玻璃使用低对比度中性渐变，镜片仍采样原生页面内容。切换底栏使用跟随方向的页面滑动，底栏选中标记随之移动。详情打开和返回采用对应方向的滑动；系统和应用的减少动态效果设置仍生效。

切页复用顶栏和现有列表。模型与插件只在缓存过期、连接状态变化或用户刷新时重新请求。相同插件数据复用列表，同一帧的更新合并绘制。API 33 将折射和柔化合并为一个着色器效果，缩小镜片采样区域并复用镜片绘制记录。

## 验收

Java 17、API 28 链接、核心接口及数据解析检查通过。Skia 像素测试验证了着色器对背景颜色的响应和边缘折射。ARM64 与 x86_64 沿用原签名，均完成 16 KB 对齐、核心和 Bun 完整性校验。内置核心为 v0.1.4342。
