# 1.1 界面改版

用户反馈旧界面显得廉价，并明确选择「浅色极简专业工具：黑白灰、精细排版、克制强调色」。本会话生成的黑白灰工作台视觉稿作为方向参考。

已实现：

- 以工作台为首页，移除宣传式大标题、大面积绿色和四块空泛的功能磁贴。
- 原生深色网关操作区、三个真实配置指标、带分隔线的功能列表、单行接入指南。
- Lucide 0.468.0 标准图标转换为 Android 原生 VectorDrawable，附完整许可；统一笔画、尺寸与导航交互。
- 主色黑白灰、细边线、少量靛蓝操作强调和绿色运行状态；采用一致的字体层级和间距。
- 管理页使用同一套原生导航，保留真实上游导航 DOM；「全部功能」动态包含已安装插件页面。
- 工作台概览由受鉴权的只读 API 获取；读取失败显示未获取状态，不当作零。

改版复核修复了三个回归：Android body 样式标记、路由组未保存内容的确认，以及动态插件页面导航。对应浏览器测试均确认修复前失败、修复后通过。

源内容仍使用上游网关、供应商与路由 API；视觉改版没有替换为静态演示数据。Android UI 与原版核心分别显示自己的版本：应用 1.1.0、沿用已验证的内置网关核心。

## 用户再次反馈后的排版修订

用户明确指出字体、卡片与排版仍显劣质，并要求确保功能真实可用。继续沿用既定黑白灰方向：引入有 OFL 许可的 Noto Sans SC / Inter，统一中文字重与等宽数字特性；首页只保留网关主操作区，今日用量和管理入口改为分区与细分隔线；统计取消指标、趋势、Token、排行各自的外框，统一内容左右边距和数字层级。管理页的字体只通过两个精确同源公共资源地址提供，不开放任意文件。

功能验收增加安卓账本调用/Token 的精确增量与备份错误口令拒绝、正确口令恢复。布局复测使用实际安装 APK；软件模拟器曾有 ColorBuffer 错误、System UI 崩溃和黑色过渡帧，另换 swiftshader 且禁用 Vulkan 复测，失败记录保留。
