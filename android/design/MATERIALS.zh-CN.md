# Magpie Android 1.3 设计素材来源

- Phosphor 官方双彩图标： https://github.com/phosphor-icons/core ，MIT。用于快捷管理、导航、网关图形、空状态与按钮。
- Radix Colors： https://www.radix-ui.com/colors ，MIT。采用 Iris / Mauve 色系构成浅紫灰背景、鸢尾紫强调和中性文字。
- Linear 官方设计复盘： https://linear.app/now/how-we-redesigned-the-linear-ui 。仅研究对齐、层级及浅色主题；其截图和网页图像没有打包进 APK。
- Magpie 鸟形标记：来自原项目 site/public/img/add-to-magpie-light.svg，原项目 MIT 许可。
- 中文与数字字体沿用已打包的 Noto Sans SC / Inter，保留 SIL OFL 许可。

精确上游提交、每份素材下载 URL 和 SHA-256 见 android/assets/design/SOURCES.json。全部素材随 APK 离线可用，不靠远程图片托管。界面预览为安装 APK 的真实 Android View/Canvas 渲染，测试账本来自实际网关请求，没有注入演示数字。
